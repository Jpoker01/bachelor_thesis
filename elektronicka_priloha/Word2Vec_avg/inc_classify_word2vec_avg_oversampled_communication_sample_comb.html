def filter_document(word2vec_model, doc):
    # remove out-of-vocabulary words
    doc = [word for word in doc if word in word2vec_model.wv]
    if(len(doc) > 0):
        return True
    else:
        return False

Function to filter out all sentences which do not word2vec model cannot create an embedding for

In [23]:
def remove_rows_without_vector(df, word2vec_model):
    for index, row in df.iterrows():
        if filter_document(word2vec_model, row['data']) == False:
            df.drop(index, inplace=True)
    return df

Function to create document vectors

In [25]:
def document_vector(word2vec_model, doc):
    # remove out-of-vocabulary words
    doc = [word for word in doc if word in word2vec_model.wv]
    return np.mean(word2vec_model.wv[doc], axis=0)
